
O AWS RAM permite que você compartilhe recursos AWS com outras contas de maneira segura e eficiente. Com o RAM, você pode evitar a duplicação de recursos e custos ao compartilhar recursos como sub-redes de **[[AWS VPC|VPC]]**, *transit gateways* (tópico de **[[Guia AWS - Redes na AWS|rede (VPC)]]**), e licenças do AWS License Manager entre diferentes contas AWS dentro de sua organização.

## Principais características
- Compartilhamento seguro de recursos dentro de uma organização ou com contas individuais.
- Redução de custos, evitando a duplicação de recursos.
- Controle de quem pode acessar e modificar os recursos compartilhados.
