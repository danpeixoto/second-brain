AWS Outposts é um serviço de infraestrutura híbrida que permite que você execute a tecnologia da AWS no seu próprio data center ou em um ambiente de colocation, com a mesma API de recursos locais (por exemplo **[[AWS EC2|EC2]]** na borda) e ligação à nuvem via **[[AWS Direct Connect|Direct Connect]]** e **[[Guia AWS - Redes na AWS|VPC]]** estendida.

## Características principais
- **Consistência híbrida**: AWS Outposts oferece uma experiência operacional unificada, permitindo o uso das mesmas APIs, ferramentas e serviços da AWS em nuvem e on-premises.
- **Baixa latência**: Ao manter cargas de trabalho e dados localmente, o Outposts oferece baixa latência para aplicações que exigem processamento local rápido.
- **Gerenciamento centralizado**: O Outposts é totalmente gerenciado pela AWS, o que significa que a AWS cuida de atualizações, manutenção e monitoramento do hardware e software.

## Casos de uso
- **Processamento de dados em tempo real**: Ideal para cargas de trabalho que exigem baixa latência, como processamento de vídeo ou IoT.
- **Armazenamento local de dados sensíveis**: Permite manter dados sensíveis localmente por questões de conformidade e regulamentação.
- **Migração gradual para a nuvem**: Serve como uma solução intermediária para organizações que desejam mover gradualmente suas cargas de trabalho para a nuvem.

## Serviços suportados
- AWS Outposts suporta uma variedade de serviços como Amazon EC2, Amazon EBS, Amazon RDS, Amazon S3, entre outros.

## Integração com outros serviços
AWS Outposts se integra facilmente com outros serviços da AWS, como VPC, IAM, CloudWatch, e outros, permitindo um gerenciamento e monitoramento simplificados.
