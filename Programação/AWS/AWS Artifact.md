
AWS Artifact é um serviço que fornece acesso sob demanda a relatórios de auditoria e documentos de conformidade da AWS. Complementa o uso do [[AWS Well-Architected Framework|Well-Architected Framework]] e de controles de segurança em serviços como [[AWS Security Hub|Security Hub]]. Ele é usado principalmente para ajudar as organizações a cumprir requisitos regulatórios e de conformidade ao utilizar os serviços da AWS.

## Características principais
- **Acesso a relatórios de conformidade**: Permite o download de diversos relatórios de conformidade, como ISO, SOC, PCI DSS e muitos outros, que demonstram os padrões de segurança que a AWS atende.
- **Gerenciamento de acordos**: Oferece acesso a acordos de confidencialidade (NDA) e acordos de processamento de dados (DPA), que podem ser necessários para determinadas regulamentações.
- **Atualizações constantes**: Os documentos e relatórios são atualizados regularmente, assegurando que os clientes tenham acesso às informações mais recentes sobre a conformidade da AWS.

## Tipos de documentos disponíveis
- **Relatórios de auditoria (Audit Reports)**: Relatórios de terceiros que avaliam a conformidade da AWS com padrões como SOC 1, SOC 2, ISO 27001, e PCI DSS.
- **Acordos de conformidade (Agreements)**: Contratos que podem ser assinados digitalmente para atender a requisitos de conformidade específicos, como GDPR.

## Casos de uso
- **Verificação de conformidade**: As organizações podem usar os relatórios do Artifact para verificar se os serviços da AWS atendem aos seus requisitos de conformidade.
- **Auditorias internas e externas**: Os documentos do AWS Artifact podem ser usados para facilitar processos de auditoria interna ou externa.
- **Provas para clientes e reguladores**: As empresas podem apresentar os relatórios do AWS Artifact como evidência de que estão utilizando uma infraestrutura que segue padrões de segurança e conformidade.

## Como acessar
- O AWS Artifact pode ser acessado diretamente pelo console da AWS, na seção de "Conformidade" (Compliance).
