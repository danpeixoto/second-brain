# Quanto investir?
Comece com o que você tem, não fique barrado esperando um valor mínimo para começar, senão você nunca vai começar.

Porém, é interessante você começar com no mínimo 100 reais. Isso permite que você testar alguns produtos e até mesmo fazer algumas vendas

# Como pagar o google
O anunciante paga toda vez que algum usuário clique no anúncio, e o valor mostrado para você virá em custo por clique (CPC). Uma vantagem disso é que ==**você só vai pagar para o google quando algum usuário clicar e não quando aparecer para ele**==. Quanto maior a qualidade do anúncio, melhor ele será ranqueado.
